# HierarchicalCompanyClassification
This repository contains the code used for my master thesis Hierarchical Company Classification into the Global Industry Classification Standard using Large Language Models.

It contains a small scraping script, some sample data from different steps in the processing pipeline, all of the python files containing full implementations as well as test versions for the classification and training loops, and the notebook used to execute most of the code.
Since the datasets are incomplete and all of the LLM-related code requires API keys, most of it will likely not run.
